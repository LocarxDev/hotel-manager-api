# Hotel Manager PRO — API

Backend multi-hotel (Node + Express + PostgreSQL). Publicado no Railway.

Variáveis: `DATABASE_URL`, `JWT_SECRET`, `MASTER_EMAIL`, `MASTER_PASSWORD`, `MASTER_NOME`, `FRONTEND_ORIGIN` (veja `.env.example`).
As tabelas são criadas automaticamente na inicialização. Comando de start: `npm start`.
